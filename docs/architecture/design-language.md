# 设计语言

> 状态：MVP 1 界面已定稿，数值取自原型（`prototype/ui` 分支的 `prototypes/`）。实现时以本文为准；原型和本文不一致时，改本文再改实现。

Atrium 的界面要做到三件事：**清新、现代**（视觉对齐 DeepSeek Harness），**有操作的实体感**（动效对齐 Apple），**看得见内部**（过程、用量、状态都能看到，但默认不吵）。

## 原则

1. **克制**：颜色少、线条细、装饰少。高级感来自材质和动效的分寸，不来自颜色堆砌。
2. **结果优先，过程可展开**：默认只突出回复和结论，过程收成一行摘要，需要时再展开。
3. **状态靠形状区分，不只靠颜色**：每种状态有自己的图标或动画，色弱用户也能分辨。
4. **一种视觉语言贯穿**：圆角方点阵列是 Atrium 的标志性元素，出现在"开始设置"按钮、模型按钮、推理强度框里。
5. **跟随系统**：浅色、深色、减弱动态效果都跟随 macOS 设置，用户可以手动覆盖外观。

## 颜色

所有颜色以 CSS 变量提供，浅色和深色两套。深色取 DeepSeek Harness 实测值，浅色按深色的层级关系推导。

变量名避开了 shadcn/ui 的约定名（`--background`、`--muted`、`--accent` 等，Streamdown 也读它们）：强调色叫 `--tint`，两级弱文字叫 `--text-muted`、`--text-dim`。shadcn 的变量由这些设计变量映射而来，见 `packages/ui/src/design/tokens.css`。

### 线与交互态

- 细线：`--line`（深 `rgba(255,255,255,.10)` / 浅 `rgba(0,0,0,.08)`），另有 `--line-soft` 与 `--line-strong`。线宽一律 0.5px，用 `box-shadow: inset 0 0 0 .5px` 画，不用 border。
- 悬停 `--hover`（深 5% 白 / 浅 3.5% 黑），选中 `--selected`（深 8% / 浅 6%）。
- 焦点环：`0 0 0 3px` 的强调色（深 22% / 浅 16% 透明度）。
- 过程轨道（2026-10-12 定）：竖线 `--rail`（深 15% 白 / 浅 15% 黑），岔出去、汇进来的曲线 `--branch`（深 28% / 浅 26%，比竖线略深才看得见弯），做完的节点 `--node`（深 `#5d6067` / 浅 `#c4c4c9`）。文件胶囊的投影 `--chip-shadow`（0.5px 细线加 1px 投影：浅 9% 黑线、5% 黑影 / 深 10% 白线、30% 黑影）。类型图标的颜色是图标自己的（M1.12 起，见"消息流 · 文件胶囊"），原先的 `--file-*` 变量去掉。
- 进行中的行：`--linked`（强调色，深 14% / 浅 10% 透明度）作底色，配 1px 强调色描边，用于登录中的服务商、有新版本的更新块（M1.10，照设置原型）。

### 品牌渐变

用于"拉满"和品牌时刻（欢迎页、极高推理强度）：蓝 `#5e84ff` → 青 `#78d6d6` → 桃 `#ffaa78`，可加紫 `#b48cff`。只在少数位置使用，不用作常规强调色。

## 字体

- 界面正文：系统字体 `-apple-system, "SF Pro Text", "PingFang SC"`；等宽 `"SF Mono", ui-monospace, Menlo`。
- 首次启动的标题：中文 **汇文明朝体**，英文 **Syne**（700）。只打包标题用到的字的子集；汇文明朝体只有一种字重，声明为可变字重以免浏览器伪加粗。产品主界面不用这两种字体。

| 变量 | 值 | 用途 |
|---|---|---|
| `--fs` | 14px | 正文、侧栏行 |
| `--fs-reply` | 14.5px | 回复正文（行高 1.55，`--lh-reply`；段落、列表、代码块之间 12px，列表项上下各 2px。2026-10-12 由行高 1.68、段间 16px、列表项 4px 收紧，字号不变，提高信息密度） |
| `--fs-meta` | 13px | 过程行、菜单项、卡片标题 |
| `--fs-sm` | 12px | 时间、标签、状态栏 |

## 阴影与材质

- 卡片：0.5px 细线 + 带蓝调的柔和投影（深 `0 9px 27px rgba(41,70,122,.20)`，浅 `.08`），变量 `--card-shadow`。对话框卡片、错误卡片用它，圆角 `--r-card`。
- 浮层（菜单、详情卡片、面板）：`--float-shadow`，深色下底色用 `--surface-2`。
- 玻璃（胶囊、产品预览）：半透明渐变底 + `blur(28px) saturate(1.7)` + 顶部 1px 高光 + 0.5px 亮边。
- 侧栏：桌面端透出 macOS 的侧栏材质（Electron `vibrancy: "sidebar"`，同 DeepSeek Harness）：模糊窗口后面的桌面，跟随外观变浅变深；窗口不在前台时也保持原样，不变灰（`visualEffectState: "active"`，2026-10-15 自用时改，原先跟着窗口变灰，切到别的应用时侧栏一下子变色）；页面的窗口底色和侧栏底色都透明，主区、首次启动等仍是不透明的（2026-10-13 自用时改，原先侧栏只透出页面自己的窗口底色）。没有系统材质时（浏览器里）深色半透明 + 背景模糊，浅色是不透明的渐变（见"层级"的 `--sidebar-bg`）。

## 标志

Atrium 的标志是一只猫，守在中庭里的伙伴，你切走了它也在后台接着干活（2026-10-11 定，从猫、猫头鹰、海狸三个方向里选定）。画法照 [ip-as-logo](https://github.com/s1dashu/ip-as-logo-skill) 的规则：

- 一个圆钝的整体轮廓（耳朵顺着脸的两侧长出来，所有角都是圆的），从右下角探出来、占满画面。
- 三种颜色：奶白的身体（`#fbf5ec` → `#eadcc8` 的轻微渐变）、墨蓝的五官 `#1f2537`、灰调蓝的底 `#6c86cc`。
- 五官只有两个竖椭圆的眼睛和一个圆角三角的鼻子，没有嘴和其他细节；16px 下仍认得出。

用在三处（界面里贯穿的元素仍是点阵）：

- 应用图标：`apps/desktop/assets/icon.svg` 按 macOS 图标网格把原图放进 1024 画布中间 824×824、圆角 185 的方块，下方一层淡投影；`icon.icns` 是它渲染成 16–1024px 十档后用 `iconutil -c icns` 合成的。改了原图要重新导出这两个文件。
- 欢迎页的 logo 位：原图 `packages/ui/src/design/brand/atrium.svg`（方形、直角）裁成 68px、圆角 22px 的方块，外圈一团淡蓝光。
- 运行中的小猫（2026-10-11 定，从社区常见的 11 种 loading 效果里选的）："进行中"前面一个 18px 的圆角方块小猫，取原图的耳朵和眼睛，平涂不加渐变，用内联 SVG 画；每 2.6 秒眨一次眼（眼睛纵向压扁再恢复，约 0.15 秒）。减弱动态效果时不眨。

## 图标

- 图标库：**Hugeicons** 免费版的 stroke-rounded（MIT，`@hugeicons/core-free-icons` + `@hugeicons/react`）：圆头圆角、软方形，比原先的 Phosphor 更圆润（2026-10-12 定，从 Lucide、Tabler、Hugeicons、Solar、Fluent、Iconoir、Material Symbols 等 11 套里比较后选的方案 B）。只用免费版里的图标，不用 Pro。
- 线宽统一 1.75（24 栅格），14px 时在屏幕上约 1px；需要加粗的（勾、更多、回到底部、发送、领先的箭头）给 2.25–2.5；实心的（停止方块、改动的圆点）填色。
- 代码里一律经 `packages/ui/src/design/icons.tsx` 取图标，它定好每个图标和线宽，界面不直接 import 图标库。
- 尺寸 10–18px。Hugeicons 没有的品牌标借 Tabler（MIT，同为 24 栅格、圆头圆角），内联在 `icons.tsx` 里并注明来源。
- 纯线性图标，只给图标上色，不加圆形或方形底色（对齐 DeepSeek Harness）。例外：侧栏行的归档按钮（见"侧栏"）。
- 品牌图标（模型服务商、pi）一律用官方资源，来源记录在 `prototypes/brand/SOURCES.md`；放在白底圆角小方块里，浅色、深色下都清楚。没有官方图标的服务商才用首字母。
- 走套餐的签（2026-10-19 自用时加）：服务商图标右下角一个蓝底小签写"套餐"，高 12px、圆角 4px、`--tint` 底、字 8px 600、颜色同面板底色，外面一圈 1.5px 面板底色的描边把它和图标隔开；右上角仍是"当前模型"的小点，两者不重叠。哪些服务商算走套餐见 SPEC-0001"输入框 · 模型选择"。

运行中的点阵涡旋（2026-10-20 自用时改，原型 `prototype/ui` 分支 `prototypes/running-indicator-art-prototype.html` 的 E；原先是 Hugeicons `loading-03` 的一圈放射短线在转，太常规）：

## 点阵

圆角方点阵列是 Atrium 的标志性元素。

- 规格：点 3.6–4.4px，圆角 1–1.3px，间距 6px。用 canvas 绘制。
- 明暗图案：两层平滑噪声（大块 + 细节）决定每个点的深浅。种子取本机安装 ID，所以每个人看到的图案不同，同一个人每次相同。
- 普通状态：单色（深色白、浅色黑），低透明度。
- 拉满状态：按横向位置着品牌渐变色（蓝 → 青 → 桃），每个点带轻微闪烁；每 3.6 秒一道 `\` 方向的光从左扫过（0.9 秒，先加速后减速）；容器外圈泛淡蓝光（`0 0 16px -4px rgba(94,132,255,.5)`），档位字变渐变色。
- 文字压在点阵上时，加一层与背景同色的文字阴影，保证清晰。
- 用在：
  - **"开始设置"按钮**：近黑胶囊，一条 `\` 方向的斜光带一次性从左扫到右（悬停 0.85 秒、平时每 6 秒一次 1.1 秒），中段最宽、铺满按钮，位移按 `cubic-bezier(.7, 0, .2, 1)`。
  - **模型按钮**：点阵从左往右铺，覆盖度表示推理强度。
  - **推理强度框**：同一块区域的覆盖度就是档位，见下文"推理强度框"。

## 动效

对齐 Apple 的弹簧参数（duration + bounce），生成 CSS `linear()` 曲线：

| 名称 | 参数 | 用途 |
|---|---|---|
| smooth | duration 0.42s，bounce 0 | 展开、收起、内容切换 |
| snappy | duration 0.30s，bounce 0.15 | 按钮回弹、弹出浮层 |
| bouncy | duration 0.40s，bounce 0.26 | 发送 / 停止切换、强调型反馈 |

- **按下的实体感**：按下 80ms 内缩到 0.95（行 0.985、小按钮 0.9），松开用 snappy 回弹。对话区的按钮都有（2026-10-15 自用时补，原先只在首次启动里实现）：小按钮（复制、分叉、回到底部）0.9，文字按钮和胶囊（"改了 N 个文件"、文件胶囊、错误卡片的按钮）0.95，整行（过程标题、步骤行、探索行、改动列表的行、压缩提示）0.985。用三个类 `atrium-press-sm`、`atrium-press`、`atrium-press-row`。
- **复制成功**：复制按钮的图标换成 ✓（`--ok-text`），2 秒后换回，同代码块的复制。
- **展开箭头**："改了 N 个文件"的箭头转半圈同 `.atrium-fold-chevron`（0.3 秒 snappy），不再一下跳过去。
- **进出场**：新内容从下方 6–10px 淡入；位置变化用 FLIP；删除先收起再移除；主题切换用 View Transitions 交叉淡化。
- **Fast 加速**：打开 Fast 时闪电一冲加三道速度线，见"组件要点"的 Fast 按钮。
- **扫光文字**：运行中的"进行中"用 2.2 秒一轮的明暗扫光，前面配运行中的小猫（见"标志"）。
- **流式输出**：按积压量平滑揭示，约 150ms 追平，不按增量到达直接绘制。
- **过程轨道**（2026-10-12 定）：
  - 新的一步：节点按 bouncy 从 0.3 倍弹出，上方那段竖线 0.24 秒从上往下长出来，文字从下方 6px 淡入（smooth，晚 60ms）。做完时圆弧收进圆点，动词换成过去时。
  - 跑完：标题行的小猫换成箭头时淡入、从 0.6 倍放大。
  - 折叠：完成后停 1 秒。高度从实测值收到 0，0.4 秒，`cubic-bezier(.45, 0, .15, 1)`（先缓后快、轻柔落定，整段收拢看得清；用 smooth 的话前 180ms 就收完九成，看着还是"啪"一下）。各行同时从下往上依次淡出、上移 6px（0.22 秒 smooth，每行晚 14ms，最多晚 120ms）。箭头按 snappy 从 ⌄ 转到 ›；收拢到 160ms 时，标题行末尾的摘要从左边 4px 处淡入（0.26 秒）。
  - 展开：反向。高度 0.4 秒展开，各行从上往下依次淡入（0.26 秒，晚 40ms 起，每行再晚 14ms，最多晚 120ms），摘要先 0.12 秒淡出。
  - 速度（2026-10-12 改）：原先高度 0.56 秒、各行 0.28 / 0.32 秒、摘要晚 220ms，自用时嫌慢，整体约快三成。
- **侧栏项目展开收起**（2026-10-12 自用时加）：同过程轨道的折叠，只是快一些：下面的工作区行一起收拢、展开，高度 0.28 秒 `cubic-bezier(.45, 0, .15, 1)`，各行依次淡出上移 / 淡入（参数同过程轨道）；后面的项目跟着平滑移动，不跳。文件夹图标在合上和打开之间交叉淡化，旧的缩到 0.6 倍淡出、新的从 0.6 倍放大淡入，颜色同时在 `--text-muted` 和 `--tint` 之间过渡，都按 snappy（0.3 秒）。打开侧栏时不播。
- **收件箱展开收起**（2026-10-13 自用时加）：同侧栏项目展开收起：列表高度 0.28 秒 `cubic-bezier(.45, 0, .15, 1)`，卡片往上长、标题行不动；各行（含"还有 N 条""收起"）依次淡出上移 / 淡入，参数同过程轨道；列表超过 228px 时高度只展开到 228px。标题行右侧的箭头按 snappy（0.3 秒）在 ⌃ 和 ⌄ 之间转半圈，各状态图标随展开收起直接隐去 / 出现。打开侧栏时不播。
- **左栏折叠展开**（2026-10-13 自用时加）：侧栏宽度 0.24 秒在 270px 和 0 之间变化，`cubic-bezier(.2, .8, .2, 1)`（先快后慢：按下就动，再轻轻停住；起初用侧栏项目展开收起的 `cubic-bezier(.45, 0, .15, 1)`，前 80ms 几乎不动，点完像顿了一下，2026-10-13 改）；里面的内容保持 270px 宽，折叠时淡出（0.2 秒）并左移 24px、被裁掉，展开时反向；对话区跟着平滑变宽、内容平滑居中。开关同时按同一曲线从侧栏右上角移到红绿灯右边（展开时移回），标签栏的左边距同样过渡。
- **右栏打开收起**（2026-10-13 自用时加）：面板宽度 0.24 秒在 0 和它的宽度之间变化，曲线同上；面板内容保持宽度，贴着左边缘一起滑进滑出，伸到窗口外的部分被裁掉（2026-10-13 改：起初内容钉在右边、左边缘从它上面滑过，收起时代码停在原地，到最后才一下消失）。拖动分隔线时宽度跟手，不加过渡。
- **推理强度框**：拖动时覆盖边缘跟手，超出两端按橡皮筋阻尼；松手后弹簧吸附（response 0.38s、damping 0.72）；到头再按方向键轻轻顶一下。
- **减弱动态效果**：所有动画降为 1ms；点阵只保留静态图案，环境光和浮动停止。
