# 设计语言

> 状态：MVP 1 界面已定稿，数值取自原型（`prototype/ui` 分支的 `prototypes/`）。实现时以本文为准；原型和本文不一致时，改本文再改实现。

Atrium 的界面要做到三件事：**清新、现代**（视觉对齐 DeepSeek Harness），**有操作的实体感**（动效对齐 Apple），**看得见内部**（过程、用量、状态都能看到，但默认不吵）。

## 原则

1. **克制**：颜色少、线条细、装饰少。高级感来自材质和动效的分寸，不来自颜色堆砌。
2. **结果优先，过程可展开**：默认只突出回复和结论，过程收成一行摘要，需要时再展开。
3. **状态靠形状区分，不只靠颜色**：每种状态有自己的图标或动画，色弱用户也能分辨。
4. **一种视觉语言贯穿**：圆角方点阵列是 Atrium 的标志性元素，出现在"开始设置"按钮、模型按钮、推理强度框里。
5. **跟随系统**：浅色、深色、减弱动态效果都跟随 macOS 设置，用户可以手动覆盖外观。

## 颜色

所有颜色以 CSS 变量提供，浅色和深色两套。深色取 DeepSeek Harness 实测值，浅色按深色的层级关系推导。

变量名避开了 shadcn/ui 的约定名（`--background`、`--muted`、`--accent` 等，Streamdown 也读它们）：强调色叫 `--tint`，两级弱文字叫 `--text-muted`、`--text-dim`。shadcn 的变量由这些设计变量映射而来，见 `packages/ui/src/design/tokens.css`。

### 线与交互态

- 细线：`--line`（深 `rgba(255,255,255,.10)` / 浅 `rgba(0,0,0,.08)`），另有 `--line-soft` 与 `--line-strong`。线宽一律 0.5px，用 `box-shadow: inset 0 0 0 .5px` 画，不用 border。
- 悬停 `--hover`（深 5% 白 / 浅 3.5% 黑），选中 `--selected`（深 8% / 浅 6%）。
- 焦点环：`0 0 0 3px` 的强调色（深 22% / 浅 16% 透明度）。
- 过程轨道（2026-10-12 定）：竖线 `--rail`（深 15% 白 / 浅 15% 黑），岔出去、汇进来的曲线 `--branch`（深 28% / 浅 26%，比竖线略深才看得见弯），做完的节点 `--node`（深 `#5d6067` / 浅 `#c4c4c9`）。文件胶囊的投影 `--chip-shadow`（0.5px 细线加 1px 投影：浅 9% 黑线、5% 黑影 / 深 10% 白线、30% 黑影）。类型图标的颜色是图标自己的（M1.12 起，见"消息流 · 文件胶囊"），原先的 `--file-*` 变量去掉。
- 进行中的行：`--linked`（强调色，深 14% / 浅 10% 透明度）作底色，配 1px 强调色描边，用于登录中的服务商、有新版本的更新块（M1.10，照设置原型）。

### 品牌渐变

用于"拉满"和品牌时刻（欢迎页、极高推理强度）：蓝 `#5e84ff` → 青 `#78d6d6` → 桃 `#ffaa78`，可加紫 `#b48cff`。只在少数位置使用，不用作常规强调色。

## 字体

- 界面正文：系统字体 `-apple-system, "SF Pro Text", "PingFang SC"`；等宽 `"SF Mono", ui-monospace, Menlo`。
- 首次启动的标题：中文 **汇文明朝体**，英文 **Syne**（700）。只打包标题用到的字的子集；汇文明朝体只有一种字重，声明为可变字重以免浏览器伪加粗。产品主界面不用这两种字体。

| 变量 | 值 | 用途 |
|---|---|---|
| `--fs` | 14px | 正文、侧栏行 |
| `--fs-reply` | 14.5px | 回复正文（行高 1.55，`--lh-reply`；段落、列表、代码块之间 12px，列表项上下各 2px。2026-10-12 由行高 1.68、段间 16px、列表项 4px 收紧，字号不变，提高信息密度） |
| `--fs-meta` | 13px | 过程行、菜单项、卡片标题 |
| `--fs-sm` | 12px | 时间、标签、状态栏 |

## 阴影与材质

- 卡片：0.5px 细线 + 带蓝调的柔和投影（深 `0 9px 27px rgba(41,70,122,.20)`，浅 `.08`），变量 `--card-shadow`。对话框卡片、错误卡片用它，圆角 `--r-card`。
- 浮层（菜单、详情卡片、面板）：`--float-shadow`，深色下底色用 `--surface-2`。
- 玻璃（胶囊、产品预览）：半透明渐变底 + `blur(28px) saturate(1.7)` + 顶部 1px 高光 + 0.5px 亮边。
- 侧栏：桌面端透出 macOS 的侧栏材质（Electron `vibrancy: "sidebar"`，同 DeepSeek Harness）：模糊窗口后面的桌面，跟随外观变浅变深，窗口不在前台时变灰；页面的窗口底色和侧栏底色都透明，主区、首次启动等仍是不透明的（2026-10-13 自用时改，原先侧栏只透出页面自己的窗口底色）。没有系统材质时（浏览器里）深色半透明 + 背景模糊，浅色是不透明的渐变（见"层级"的 `--sidebar-bg`）。

## 标志

Atrium 的标志是一只猫，守在中庭里的伙伴，你切走了它也在后台接着干活（2026-10-11 定，从猫、猫头鹰、海狸三个方向里选定）。画法照 [ip-as-logo](https://github.com/s1dashu/ip-as-logo-skill) 的规则：

- 一个圆钝的整体轮廓（耳朵顺着脸的两侧长出来，所有角都是圆的），从右下角探出来、占满画面。
- 三种颜色：奶白的身体（`#fbf5ec` → `#eadcc8` 的轻微渐变）、墨蓝的五官 `#1f2537`、灰调蓝的底 `#6c86cc`。
- 五官只有两个竖椭圆的眼睛和一个圆角三角的鼻子，没有嘴和其他细节；16px 下仍认得出。

用在三处（界面里贯穿的元素仍是点阵）：

- 应用图标：`apps/desktop/assets/icon.svg` 按 macOS 图标网格把原图放进 1024 画布中间 824×824、圆角 185 的方块，下方一层淡投影；`icon.icns` 是它渲染成 16–1024px 十档后用 `iconutil -c icns` 合成的。改了原图要重新导出这两个文件。
- 欢迎页的 logo 位：原图 `packages/ui/src/design/brand/atrium.svg`（方形、直角）裁成 68px、圆角 22px 的方块，外圈一团淡蓝光。
- 运行中的小猫（2026-10-11 定，从社区常见的 11 种 loading 效果里选的）："进行中"前面一个 18px 的圆角方块小猫，取原图的耳朵和眼睛，平涂不加渐变，用内联 SVG 画；每 2.6 秒眨一次眼（眼睛纵向压扁再恢复，约 0.15 秒）。减弱动态效果时不眨。

## 图标

- 图标库：**Hugeicons** 免费版的 stroke-rounded（MIT，`@hugeicons/core-free-icons` + `@hugeicons/react`）：圆头圆角、软方形，比原先的 Phosphor 更圆润（2026-10-12 定，从 Lucide、Tabler、Hugeicons、Solar、Fluent、Iconoir、Material Symbols 等 11 套里比较后选的方案 B）。只用免费版里的图标，不用 Pro。
- 线宽统一 1.75（24 栅格），14px 时在屏幕上约 1px；需要加粗的（勾、更多、回到底部、发送、领先的箭头）给 2.25–2.5；实心的（停止方块、改动的圆点）填色。
- 代码里一律经 `packages/ui/src/design/icons.tsx` 取图标，它定好每个图标和线宽，界面不直接 import 图标库。
- 尺寸 10–18px。Hugeicons 没有的品牌标借 Tabler（MIT，同为 24 栅格、圆头圆角），内联在 `icons.tsx` 里并注明来源。
- 纯线性图标，只给图标上色，不加圆形或方形底色（对齐 DeepSeek Harness）。例外：侧栏行的归档按钮（见"侧栏"）。
- 品牌图标（模型服务商、pi）一律用官方资源，来源记录在 `prototypes/brand/SOURCES.md`；放在白底圆角小方块里，浅色、深色下都清楚。

## 点阵

圆角方点阵列是 Atrium 的标志性元素。

- 规格：点 3.6–4.4px，圆角 1–1.3px，间距 6px。用 canvas 绘制。
- 明暗图案：两层平滑噪声（大块 + 细节）决定每个点的深浅。种子取本机安装 ID，所以每个人看到的图案不同，同一个人每次相同。
- 普通状态：单色（深色白、浅色黑），低透明度。
- 拉满状态：按横向位置着品牌渐变色（蓝 → 青 → 桃），每个点带轻微闪烁；每 3.6 秒一道 `\` 方向的光从左扫过（0.9 秒，先加速后减速）；容器外圈泛淡蓝光（`0 0 16px -4px rgba(94,132,255,.5)`），档位字变渐变色。
- 文字压在点阵上时，加一层与背景同色的文字阴影，保证清晰。
- 用在：
  - **"开始设置"按钮**：近黑胶囊，一条 `\` 方向的斜光带一次性从左扫到右（悬停 0.85 秒、平时每 6 秒一次 1.1 秒），中段最宽、铺满按钮，位移按 `cubic-bezier(.7, 0, .2, 1)`。
  - **模型按钮**：点阵从左往右铺，覆盖度表示推理强度。
  - **推理强度框**：同一块区域的覆盖度就是档位，见下文"推理强度框"。

## 动效

对齐 Apple 的弹簧参数（duration + bounce），生成 CSS `linear()` 曲线：

| 名称 | 参数 | 用途 |
|---|---|---|
| smooth | duration 0.42s，bounce 0 | 展开、收起、内容切换 |
| snappy | duration 0.30s，bounce 0.15 | 按钮回弹、弹出浮层 |
| bouncy | duration 0.40s，bounce 0.26 | 发送 / 停止切换、强调型反馈 |

- **按下的实体感**：按下 80ms 内缩到 0.95（行 0.985、小按钮 0.9），松开用 snappy 回弹。
- **进出场**：新内容从下方 6–10px 淡入；位置变化用 FLIP；删除先收起再移除；主题切换用 View Transitions 交叉淡化。
- **Fast 加速**：打开 Fast 时闪电一冲加三道速度线，见"组件要点"的 Fast 按钮。
- **扫光文字**：运行中的"进行中"用 2.2 秒一轮的明暗扫光，前面配运行中的小猫（见"标志"）。
- **流式输出**：按积压量平滑揭示，约 150ms 追平，不按增量到达直接绘制。
- **过程轨道**（2026-10-12 定）：
  - 新的一步：节点按 bouncy 从 0.3 倍弹出，上方那段竖线 0.24 秒从上往下长出来，文字从下方 6px 淡入（smooth，晚 60ms）。做完时圆弧收进圆点，动词换成过去时。
  - 跑完：标题行的小猫换成箭头时淡入、从 0.6 倍放大。
  - 折叠：完成后停 1 秒。高度从实测值收到 0，0.4 秒，`cubic-bezier(.45, 0, .15, 1)`（先缓后快、轻柔落定，整段收拢看得清；用 smooth 的话前 180ms 就收完九成，看着还是"啪"一下）。各行同时从下往上依次淡出、上移 6px（0.22 秒 smooth，每行晚 14ms，最多晚 120ms）。箭头按 snappy 从 ⌄ 转到 ›；收拢到 160ms 时，标题行末尾的摘要从左边 4px 处淡入（0.26 秒）。
  - 展开：反向。高度 0.4 秒展开，各行从上往下依次淡入（0.26 秒，晚 40ms 起，每行再晚 14ms，最多晚 120ms），摘要先 0.12 秒淡出。
  - 速度（2026-10-12 改）：原先高度 0.56 秒、各行 0.28 / 0.32 秒、摘要晚 220ms，自用时嫌慢，整体约快三成。
- **侧栏项目展开收起**（2026-10-12 自用时加）：同过程轨道的折叠，只是快一些：下面的工作区行一起收拢、展开，高度 0.28 秒 `cubic-bezier(.45, 0, .15, 1)`，各行依次淡出上移 / 淡入（参数同过程轨道）；后面的项目跟着平滑移动，不跳。文件夹图标在合上和打开之间交叉淡化，旧的缩到 0.6 倍淡出、新的从 0.6 倍放大淡入，颜色同时在 `--text-muted` 和 `--tint` 之间过渡，都按 snappy（0.3 秒）。打开侧栏时不播。
- **收件箱展开收起**（2026-10-13 自用时加）：同侧栏项目展开收起：列表高度 0.28 秒 `cubic-bezier(.45, 0, .15, 1)`，卡片往上长、标题行不动；各行（含"还有 N 条""收起"）依次淡出上移 / 淡入，参数同过程轨道；列表超过 228px 时高度只展开到 228px。标题行右侧的箭头按 snappy（0.3 秒）在 ⌃ 和 ⌄ 之间转半圈，各状态图标随展开收起直接隐去 / 出现。打开侧栏时不播。

  - 文字：动词 `--text-2`，对象 `--text-muted`，中间"·"用 `--text-dim`；命令用等宽 12px；右侧结果（"✓ 通过"、"失败"、"未完成"）12px `--text-dim`。进行中的动词扫光（同"进行中"）。走不通整行 `--text-dim`，插话的"你插话"用 `--tint`。
  - 文件胶囊：高 22px、胶囊圆角，`--surface-1` 底，`--chip-shadow`；左边 13px 的类型图标，文件名 12px；编辑的胶囊里接 11px 的 +N（`--ok-text`）−M（`--danger`）。胶囊之间 6px。
  - 类型图标（M1.12 改，2026-10-13 定：用官方的，不自己画；原先是 Hugeicons、Tabler 的线性图标，只给图标上色）：用 [material-icon-theme](https://github.com/material-extensions/vscode-material-icon-theme)（MIT，VS Code 最常用的图标主题，Paseo 也用它）的原版 SVG，颜色是图标自己的，不再用 `--file-*` 变量。按它的清单认：先认完整文件名（不分大小写，如 `package.json` 是 Node、`.gitignore` 是 git、`tsconfig.json` 是 TS 配置），再认最长的扩展名（`panes.test.ts` 先认 `test.ts`，是测试图标），都认不出的是它的通用文件图标。清单里还有按语言认的一张表，要 VS Code 的语言表才能用；常见的扩展名清单里都直接有，不另做（2026-10-13 实现时定）。浅色外观用它的浅色版（清单里的 `light`，如 pnpm）。只打包用得到的图标：`scripts/file-icons.mjs` 从固定版本的清单生成认法表（`packages/ui/src/files/file-icons.json`），只把表里用到的 SVG 连同许可证复制到 `packages/ui/public/file-icons/`，界面用到时才加载。文件树、查看标签、文件胶囊用同一套。

  - 详情块不变（`--code` 底、圆角 `--r`），竖线在它旁边接着往下。不做成卡片。
  - 没有内容可看的推理（模型把推理藏起来了，只有一个空块）：整行不是按钮，没有悬停底色、点不开，也没有详情块（2026-10-12 定）。
- 回复：Markdown，下方一行信息：复制、改动汇总胶囊、用量、时间。
  - 无序列表（2026-10-12 定）：圆点自己画，5px 实心、文字色，中心离行首 0.45em、在第一行的中线上，文字从 1.25em 起；折行和文字对齐，不回到圆点下面。浏览器自带的圆点后面空得太多、也调不了。有序列表照常；任务列表只有勾选框，不再带圆点。
  - 代码块、表格、Mermaid 图（2026-10-14 定，原型 `prototype/ui` 分支 `prototypes/reply-blocks-prototype.html` 的 B"平铺"；A 只补颜色、C 带标题栏的卡片没选）：都是平铺的一块，不套框、不描边，比正文安静。
    - 代码块：`--code` 底、圆角 `--r-md`，内边距 12px 14px；等宽 `--fs-mono`、行高 1.6；不显示行号；高亮照旧（Shiki `github-light` / `github-dark`），底色用 `--code`，不用主题自带的。语言名在右上角，11px 等宽 `--text-dim`，垫一层 `--code` 底（压在长行上面）。悬停或里面有焦点时，语言名 0.15 秒淡出，换成按钮：只有复制。
    - 按钮（三种块共用）：26px 见方、圆角 `--r-sm`，14px 图标，`--text-dim`；悬停 `--hover` 底、`--text-2`。按钮组垫一层和块同色的底。图标照常经 `icons.tsx` 取（复制、对勾、放大、关闭等）。
    - 表格：不加框、占满宽度；表头 13px 半粗 `--text-muted`，下面一道 1px `--line-strong`；行之间 1px `--line-soft`，最后一行下面没有线；单元格上下 8px、右边 20px，第一列贴左。悬停时右上角出现复制（可选 Markdown / CSV / TSV）和放大。
    - Mermaid：和代码块同一种面，图居中，上下 20px；右上角是 `mermaid`，悬停换成"源码"（切到源码后是"图"）、复制、放大。配色是中性的：节点 `--main` 底、`--line-strong` 边、`--text-2` 字，连线和箭头 `--text-dim`，不用 Mermaid 默认的紫色；深色外观同理换成深色的值。图里不放缩放按钮，放大后才有。
    - 行内代码：`--surface-2` 底、圆角 `--r-sm`。
    - Streamdown 按 shadcn 的颜色名写样式（`border`、`muted`、`background` 等），名字在 `tokens.css` 里对到我们的 token；回复里的块由 `styles.css` 直接按上面定的样式画，Streamdown 自己的弹出层（如放大的表格）还用它的类，这些名字要在 `styles.css` 的 `@theme` 里登记。漏登记的颜色 Tailwind 会落成文字色，就是 2026-10-14 之前代码块、表格都是黑框的原因。
- 系统事件：居中灰字，两侧细线。
- 右边缘的提问导航条：每次提问一条 10px 细横条，当前 18px，悬停 26px 并预览提问。

### 输入框

- 圆角 22 的卡片，内边距 14px；文字和右上的展开按钮再往里缩 6px，光标离卡片左边和上边都是 20px，不贴着圆角（2026-10-12 定）。展开按钮固定在卡片右上角（离上边、右边各 20px），上方有图片或胶囊时也不往下移，图片、胶囊和提示行右边让出按钮的位置（2026-10-12 自用时改，原先跟着文字框走）。左下"+"菜单（打开时旋转 45° 成"×"），右下模型按钮与发送。卡片里的按钮（"+"、展开、模型按钮、⚡、发送 / 停止）悬停时光标是小手（`pointer`），不能用时是默认光标（2026-10-12 定）。
- 发送按钮：有内容时深色实心圆（与正文同色），空时浅灰。
- Fast 按钮（M1.11，2026-10-12 定，同日改）：模型按钮左边，只有一个 15px 的 ⚡，没有圆圈、底色和描边；点按区域仍是 32px 见方，向右伸进和模型按钮之间的间隙，⚡ 离模型按钮 10.5px（2026-10-12 收紧，原先约 16px 显得太空）。关时灰色线框 ⚡（`--text-muted`，悬停变 `--text`），开时实心 ⚡、`--tint` 色。悬停时光标是小手（`pointer`），不能用时是默认光标。从关变开时播一下加速动效：闪电先往后一缩、再向右一冲、回弹到原位（约 0.5s），左边三道速度线从闪电身后往后掠过、淡出（约 0.45s，错开 40ms）；颜色 0.2s 过渡到 `--tint`。打开状态下出现的按钮（换到支持的模型、刚进入会话）不播，关掉也不播。悬停或用键盘聚焦时上方弹出说明卡片，鼠标移开就收起（点过之后按钮虽留着焦点也收起，按 `:focus-visible` 判断），做法同状态栏的详情卡片：第一行"Fast 已开启 / 未开启"，分隔线下是速度和额度（"约 2 倍速度，额度消耗增加"，速度不详时"更快"）和"从下一次请求开始生效"。当前模型不支持时整个不显示。模型菜单里支持 Fast 的模型名后带一个 11px 的实心 ⚡（`--tint`）。
- `/` 菜单（M1.11，2026-10-13 定，原型 `slash-commands-prototype.html`）：分组小标题（"内置""扩展""模板""技能"，`--fs-meta`、`--text-dim`）；每行左边 16px 类型图标，只给图标上色、不加底色：内置是斜杠（`--tint`）、extension 是拼图（`--ok-text`）、模板是文档（`--attn-text`）、skill 是星光（`--ctx-tools` 的紫）；然后是等宽的 `/名字`、`--text-dim` 的参数提示，描述靠右、`--text-muted`。置灰的行整行 `--text-dim`，不响应悬停。
- 命令标签（M1.11，方案 B）：高 22px 的胶囊，圆角 `--r-sm`，`--surface-1` 底、0.5px `--line-strong` 描边和一层很浅的投影；左边 14px 类型图标（颜色同菜单），右边名字，`--fs-meta`、500 字重、`--text` 色，左内边距 4px、右 8px、中间 5px。在输入框里和第一行文字垂直居中，文字从标签后 6px 开始（第一行缩进，折行回到行首）；在气泡里同样放在开头，后面接参数。
- 运行中压缩：消息流底部一行灰字"正在压缩上下文…"，文字上扫过一道闪光（同运行中步骤的闪光），完成后换成"上下文已压缩"的提示条。
- 失败的一轮（M1.11，2026-10-13 自用时定，原型见 `prototype/ui` 分支 `prototypes/turn-error-prototype.html` 的 C）：错误卡片是一行，`--fs-meta`：14px 图标和说明，登录失效是钥匙和 `--attn`，其他是警告和 `--danger`；后面只有一个主按钮，同色浅底（登录失效 `--attn-soft` 底、`--attn-text` 字，其他 `--danger-soft` 底、`--danger` 字）、半粗、胶囊、行高 22px、左右 10px；登录失效又能重试时"重试"是文字按钮（`--text-muted`，左右 6px，悬停 `--hover` 底、`--text-2`）；"详情"和 12px 的 › 在这一行最右，`--text-dim`（悬停 `--text-muted`、`--hover` 底），展开时 › 按 snappy 转向下，原始报错在下面的代码块里。没有回复、也没有改动的失败轮不显示下面的信息行。
- 分叉按钮（M1.11，2026-10-13 定，原型 `fork-button-prototype.html`）：回复下方信息行里复制右边，Hugeicons `git-fork`，14px，样式同复制按钮（`--text-dim`，悬停 `--hover` 底、`--text-muted`）；运行中透明度 0.4、悬停不变、鼠标是禁止样式。
- 胶囊条浮在输入框上方，消息流在上方 64px 内渐隐。
- 附件：图片用文件卡片，文件引用和粘贴内容用小胶囊。
- 发出的消息带的图片（M1.11，2026-10-12 定）：气泡上方靠右一行 64px 见方的缩略图，圆角 `--r-md`、裁成正方形填满、0.5px `--line` 描边，间隔 6px，最宽和气泡一样（80%），多了换行。加载中是 `--hover` 灰底并缓慢闪烁；取不到时是 `--surface-2` 底、居中一个 18px 的图片图标（`--text-dim`）。

### 推理强度框

高 38px、每档 56px 宽的横框，背景点阵的覆盖度就是档位，细竖线分出档数；左侧档位名，右侧"3 / 4"；在面板里水平居中。

### 状态栏

输入框正下方居中，高 28px，离输入框卡片 4px、离窗口底边 8px（2026-10-12 定，原先离输入框 24px 太散）；没有会话时留出同样的高度，输入框不跳动。按语义分组，每组"图标 + 一行摘要"，悬停或用键盘聚焦时弹出详情卡片，鼠标移开就收起，点过之后也一样（2026-10-12 定）；末尾一个调节按钮是唯一的自定义入口，面板里每项是"名称 + 说明 / 实时预览 / 开关"。

### 设置

盖在工作台上的居中窗口（最大 900×640，圆角 14px），背后是 `--scrim` 遮罩（深 `rgba(6,8,12,.42)` / 浅 `rgba(30,38,56,.30)`）加 `blur(8px)`；左栏 212px 放分类，底色 `--nav-bg`（深 2.5% 白 / 浅 2.2% 黑），右侧内容区。每组设置是"小标题 + 说明 + 行"，行之间 0.5px 细线。安装和更新的输出显示在终端块里，两种外观下都是深色（`--term` 深 `#0c0c0e` / 浅 `#17181b`，文字 `--term-text` `#d6d9de`，弱文字 `--term-dim`），底边一条进度线。详见 [SPEC-0001 · 设置](../specs/0001-mvp1-single-session-chat.md#设置)。

### 首次启动

整窗无侧栏；顶部步骤条，底部操作条（左次要、右主按钮带 ⏎）；每一步一个"展示区"承担视觉重量。欢迎页是可截图传播的首屏：logo 位（见"标志"）、"由 pi 驱动"胶囊、大标题、点阵按钮、后仰的玻璃产品预览。详见 [SPEC-0001 · 首次启动](../specs/0001-mvp1-single-session-chat.md#首次启动)。
