# 架构决策记录（ADR）

每份 ADR 记录一个影响长远、难以撤回的决策：当时的背景、选了什么、放弃了什么、带来什么后果。

## 规则

- **只追加，不修改**。决策被推翻时，写一份新 ADR，并把旧 ADR 的状态改为"已取代"，注明被哪份取代。这是唯一允许对旧 ADR 做的修改。
- **一份 ADR 一个决策**。
- 新建时复制 [template.md](template.md)，编号取下一个。

## 状态

| 状态 | 含义 |
|---|---|
| 提议 | 待讨论 |
| 已接受 | 当前生效 |
| 已废弃 | 不再适用，且没有替代决策 |
| 已取代 | 被新的 ADR 取代 |
