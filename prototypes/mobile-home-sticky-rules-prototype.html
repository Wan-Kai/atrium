「等你处理」便签 · 生成规则

D「一事一张」的规则样张。这一版：左上角改成分类（先统一"对话"），颜色只表示关注等级；右下角 + 换成纸面玻璃；标题用 Fraunces 斜体：0、1、2、5、12 件，Mac 断开时，以及贴上、撕下的动效。示例数据是虚构的。便签里第二行的原话（问题、报错）现在首页拿不到，见页尾「待你定」。

选哪些、怎么排

  1. 同桌面收件箱 inboxOf：未归档；有没答的问题算"在问你"，否则没看过的出错算"出错"，要登录的一直算"要登录"直到下次运行。
  2. 排序：先按关注等级（卡住 → 等你 → 提醒），同级里最新的在前。
  3. 最多贴 8 张；再多，第 9 个位置是"还有 N 件"的一叠，点开是完整列表页。
  4. 0 件整块不显示。

一张便签写什么

  1. 左上角是分类，不写状态：现在只有"对话"（气泡图标＋字）；以后加"待确认""TODO""收件箱"等。右上角等了多久。
  2. 标题：会话名，没有取第一句话，最多 2 行。
  3. 原话，最多 2 行：在问你写问题第一句；出错写报错第一行（等宽）；要登录写"Anthropic 登录过期，到 Mac 上重新登录"。
  4. 底行：项目 · 工作区；对话写"对话"。一行，超出省略。
  5. 整张可点，进会话；没有按钮。

长什么样

  1. 颜色是关注等级，和分类无关：卡住（出错、要登录）等你（在问你、待确认）提醒（TODO、收件箱，先留着）状态词不写在便签上，读屏时念出来（"在问你""出错"）。
  2. 尺寸固定 158 × 164；2 张正好一屏，第 3 张露出 28pt。只有 1 张时占满一行。
  3. 歪的角度、胶带位置由会话 id 算出来：同一张便签每次打开都一样，不会刷新就抖。相邻两张一左一右歪，单数张下沉 6pt。
  4. 角度 ±0.8°～±2.2°，胶带左右 40%～60%、转 ±4°。"减少动态效果"打开时全部摆正。

变化时

  1. 新来一件：从上方轻轻"贴"上（0.42 秒，略带回弹），插在它该在的位置，其余让开。
  2. 处理掉（答了、重新跑了、看过了出错）：往右上"撕"走，后面的补上。
  3. "减少动态效果"时只淡入淡出。
  4. Mac 断开：便签保留断开前的样子，褪色；重连同步完再更新。

待你定

  1. 原话那一行要宿主在会话列表里多带"问题第一句 / 报错第一行"（截短到 120 字），协议升一版；不加的话便签只有标题和位置。
  2. 写不写等了多久（SPEC-0005 现在写"不写时间"）。
  3. 只有 1 张时占满一行，还是和其他时候一样宽。
