这一版改了什么（三个变体共同）

去掉 inset grouped 的卡片和分组底色、传统导航栏和 tab bar：内容直接放在页面底色上，顶部只有悬浮的圆形玻璃按钮（菜单、搜索、新会话）。

层级：组标题（等你处理 / 对话）是 13pt 灰字；项目名是比它强的章节标题（可折叠，右边“N 在跑”）；工作区是 13pt 的小标题（分支图标在状态列、名字和会话标题对齐）；会话是 16pt 标题 + 13pt 灰色元信息两行。不靠框。

状态：行首 14pt 状态列——在问你 / 出错是小图标（形状不同），运行中是点阵涡旋，未读蓝点。元信息最多 3 项：状态 · 项目 / 工作区，或状态 · 改动量，或当前步骤 · 计时。

连接：标题下一个小胶囊“● MacBook Pro”，点它可切状态看效果；离线才展开一句说明。

玻璃只在悬浮的按钮、输入框、胶囊、长按菜单上；悬浮控件下方一段底色渐隐，内容不和玻璃打架。

保留的逻辑：工作区最多 3 个会话 + “还有 N 个”、项目可折叠、“对话”不缩进状态放行尾；运行中点发送进排队、长按发送弹“立即插话”；改动列表单行分组 32pt、右上角切按改动量排。从首页行进对话、从工作区标题进改动都是放大过渡。
