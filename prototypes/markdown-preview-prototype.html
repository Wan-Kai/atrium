Atrium

以 pi 为唯一内核的 macOS 桌面 coding agent。

把对话、文件和改动放在同一个工作区。专注当前任务，需要时看见过程。

开始开发

pnpm install --offline
pnpm dev

工作区里有什么

  • 对话：提问、插话、查看执行过程。
  • 文件：浏览目录，打开并查看源码。
  • 更改：按文件检查本次修改。

常用命令

命令 用途
pnpm dev 启动开发版
pnpm check 检查格式、类型与依赖
pnpm test 运行测试
文件查看保持只读。预览只改变显示方式，不修改 Markdown 文件。
