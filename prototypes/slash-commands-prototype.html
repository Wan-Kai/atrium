/ 命令 · 设计稿（原型，审完即弃）

pi 终端里的内置命令（/compact、/model…）在 RPC 里不会被 pi 识别，由 Atrium 自己认出来，调 pi 对应的 RPC 命令，或者打开 Atrium 里现成的界面。

选中的命令在输入框最前面变成一个标签，后面接着打参数；发出后，用户消息里也显示同样的标签。底部切换 A / B / C 三种标签画法，页面上所有标签一起变。

1. 试一试

输入 / 弹出列表（可以接着打字过滤），↑↓ 选择，回车或 Tab 选中；选中后变成标签，光标在标签后面，接着打参数。光标在最前面时按退格删掉标签，标签的文字回到输入框，可以改。

GPT-5.5 · 高

2. 命令列表

"内置"一组排在最前，后面照旧是扩展、模板、技能。每行：类型小图标、/名字、参数提示（灰色等宽）、右侧中文说明。内置命令的说明是 Atrium 写的中文，其他的用 pi 给的原文。

3. 输入框里的标签（三种画法并排）

同一条输入：/compact 加压缩要求；/skill:review 加参数。标签和文字在同一行，长文字从标签后面接着往下折行。

4. 发出之后

会发给模型的命令（扩展、模板、技能）照常留在对话里，气泡最前面是同样的标签。内置命令不发给模型，不出气泡：/compact 在原地出"正在压缩上下文…"，做完是压缩提示条；/model、/thinking 直接改输入框里的按钮；/copy、/export 这类做完弹一个小提示。

5. 内置命令怎么接（pi 1.1.0 共 25 个）

"新做"是这次要加的；"已有"是 Atrium 里已经有的能力，命令只是另一个入口；"不接"的给了理由，可以再议。
